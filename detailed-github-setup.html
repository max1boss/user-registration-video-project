🎯 Метод 1: Через poehali.dev
Автоматическая синхронизация с GitHub
ЛЕГКО
🚀 Преимущества: Все файлы добавляются автоматически, не нужно ничего копировать вручную.
📤 Вариант 1A: Если GitHub еще НЕ подключен
  • Откройте редактор poehali.dev с вашим проектом
  • В правом верхнем углу нажмите кнопку "Скачать"
  • Выберите "Подключить GitHub"
  • Нажмите "Authorize" для входа в GitHub
  • При запросе прав выберите "Все репозитории" или конкретные
  • Выберите аккаунт/организацию для создания репозитория
  • Дождитесь сообщения "Репозиторий создан"
📸 Скриншот: кнопка "Скачать" → "Подключить GitHub"

✅ Результат

Все файлы проекта, включая GitHub Actions (.github/workflows/), автоматически попадут в новый репозиторий.
🔄 Вариант 1B: Если GitHub уже подключен
  • Откройте редактор poehali.dev с вашим проектом
  • Найдите кнопку "GitHub" в интерфейсе
  • Нажмите "Push Changes" или "Синхронизировать"
  • Подтвердите отправку изменений
  • Дождитесь завершения синхронизации
📸 Скриншот: кнопка "GitHub" → "Push Changes"

⚠️ Важно

После синхронизации перейдите в свой GitHub репозиторий и убедитесь, что папка .github/workflows/ появилась в корне проекта.
🔧 Метод 2: Ручное добавление
Копирование файлов напрямую в GitHub
СРЕДНЕ
🔧 Когда использовать: Если автоматическая синхронизация не работает или у вас уже есть отдельный GitHub репозиторий.
🗂️ Шаг 1: Создание структуры папок

В корне вашего GitHub репозитория должна быть такая структура:

📁 ваш-репозиторий/ ├── 📁 .github/ │ └── 📁 workflows/ │ ├── 📄 manual-build.yml │ └── 📄 build-android-apk.yml ├── 📁 src/ ├── 📄 package.json └── 📄 README.md

Способы создания папок:

  • Через веб-интерфейс GitHub: Create new file → введите .github/workflows/manual-build.yml
  • Через командную строку: mkdir -p .github/workflows
  • Через файловый менеджер: создайте папки вручную
📄 Шаг 2: Создание первого файла workflow

Создайте файл .github/workflows/manual-build.yml со следующим содержимым:

name: 🎯 Manual APK Build on: workflow_dispatch: inputs: version: description: '📋 Версия приложения (например: 1.2.0)' required: true default: '1.0.0' type: string build_type: description: '🔧 Тип сборки' required: true default: 'release' type: choice options: - release - debug create_release: description: '🏷️ Создать GitHub Release?' required: false default: false type: boolean jobs: manual-build: name: 🚀 Manual Android Build runs-on: ubuntu-latest timeout-minutes: 45 steps: - name: 📥 Checkout code uses: actions/checkout@v4 - name: ☕ Setup Java 17 uses: actions/setup-java@v4 with: java-version: '17' distribution: 'temurin' - name: 🚀 Setup Node.js 20 uses: actions/setup-node@v4 with: node-version: '20' cache: 'npm' - name: 🤖 Setup Android SDK uses: android-actions/setup-android@v3 with: api-level: '34' build-tools: '34.0.0' - name: 📦 Install dependencies run: | npm ci npm install -g @capacitor/cli - name: 🏗️ Build React application run: npm run build - name: 📱 Setup Capacitor Android run: | if [ ! -d "android" ]; then npx cap add android fi npx cap sync android - name: 🔨 Build Android APK run: | cd android chmod +x gradlew if [ "${{ inputs.build_type }}" == "release" ]; then ./gradlew assembleRelease --no-daemon else ./gradlew assembleDebug --no-daemon fi - name: 📂 Prepare APK file id: prepare_apk run: | if [ "${{ inputs.build_type }}" == "release" ]; then APK_PATH=$(find android -name "*release*.apk" -type f | head -1) else APK_PATH=$(find android -name "*debug*.apk" -type f | head -1) fi FINAL_NAME="imperia-promo-v${{ inputs.version }}-${{ inputs.build_type }}.apk" cp "$APK_PATH" "$FINAL_NAME" echo "apk_path=$FINAL_NAME" >> $GITHUB_OUTPUT - name: 📤 Upload APK uses: actions/upload-artifact@v4 with: name: IMPERIA-PROMO-v${{ inputs.version }}-${{ inputs.build_type }} path: ${{ steps.prepare_apk.outputs.apk_path }} retention-days: 90 - name: 🏷️ Create GitHub Release if: inputs.create_release uses: softprops/action-gh-release@v1 with: tag_name: v${{ inputs.version }} name: "IMPERIA PROMO v${{ inputs.version }}" body: | ## 📱 IMPERIA PROMO v${{ inputs.version }} ### 📥 Установка: 1. Скачайте APK файл ниже 2. Включите "Неизвестные источники" в Android 3. Установите APK файл ### 🚀 Возможности: - 📹 HD/4K видеозапись - 📤 Фоновая загрузка файлов - 💾 Офлайн сохранение files: ${{ steps.prepare_apk.outputs.apk_path }} draft: false prerelease: ${{ inputs.build_type == 'debug' }} env: GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
📄 Шаг 3: Создание второго файла workflow

Создайте файл .github/workflows/build-android-apk.yml:

name: 🚀 Build Android APK on: push: branches: [ main, master ] tags: [ 'v*' ] pull_request: branches: [ main, master ] workflow_dispatch: jobs: build-android: name: 📱 Build Android APK runs-on: ubuntu-latest timeout-minutes: 30 steps: - name: 📥 Checkout repository uses: actions/checkout@v4 - name: ☕ Setup Java JDK uses: actions/setup-java@v4 with: java-version: '17' distribution: 'temurin' - name: 🚀 Setup Node.js uses: actions/setup-node@v4 with: node-version: '20' cache: 'npm' - name: 🤖 Setup Android SDK uses: android-actions/setup-android@v3 with: api-level: '34' build-tools: '34.0.0' - name: 📦 Install dependencies run: | npm ci npm install -g @capacitor/cli - name: 🏗️ Build React app run: npm run build - name: 🔧 Initialize Capacitor Android run: | if [ ! -d "android" ]; then npx cap add android fi npx cap sync android - name: 🔨 Build Android APK run: | cd android chmod +x gradlew ./gradlew assembleDebug --no-daemon --stacktrace - name: 📂 Locate APK files id: locate_apk run: | APK_PATH=$(find android -name "*.apk" -type f | head -1) if [ -z "$APK_PATH" ]; then echo "❌ No APK files found" exit 1 fi APK_SIZE=$(du -h "$APK_PATH" | cut -f1) FINAL_NAME="imperia-promo-latest.apk" cp "$APK_PATH" "$FINAL_NAME" echo "apk_path=$FINAL_NAME" >> $GITHUB_OUTPUT echo "apk_size=$APK_SIZE" >> $GITHUB_OUTPUT - name: 📤 Upload APK artifact uses: actions/upload-artifact@v4 with: name: imperia-promo-latest path: ${{ steps.locate_apk.outputs.apk_path }} retention-days: 30
💾 Шаг 4: Сохранение изменений

Через веб-интерфейс GitHub:

  • Нажмите "Commit new file" после создания каждого файла
  • Добавьте описание: "Add GitHub Actions for Android APK build"
  • Выберите "Commit directly to main branch"

Через командную строку:

git add .github/ git commit -m "Add GitHub Actions for Android APK build" git push origin main
✅ Проверка и запуск
Тестирование настроенных workflow
🔍 Шаг 1: Проверка файлов
  • Откройте ваш GitHub репозиторий
  • Убедитесь, что в корне есть папка .github/workflows/
  • Проверьте наличие файлов manual-build.yml и build-android-apk.yml
  • Откройте любой файл и убедитесь, что содержимое корректное
📸 Скриншот: структура файлов в GitHub репозитории
🚀 Шаг 2: Первый запуск
  • Перейдите на вкладку "Actions" в репозитории
  • Найдите workflow "🎯 Manual APK Build"
  • Нажмите на него, затем "Run workflow"
  • Заполните параметры:
    • Версия: 1.0.0
    • Тип сборки: release
    • Создать Release: ✅ да
  • Нажмите зеленую кнопку "Run workflow"
📸 Скриншот: страница Actions с кнопкой "Run workflow"
⏱️ Шаг 3: Ожидание результата
  • Процесс сборки займет 10-15 минут
  • Следите за прогрессом в режиме реального времени
  • Вы получите email уведомление о завершении
  • При успешной сборке статус будет ✅ Success
💡 Совет: Оставьте вкладку открытой, чтобы наблюдать за процессом. Каждый шаг будет отмечаться галочкой по мере выполнения.
📥 Шаг 4: Получение APK

Способ 1 - Из GitHub Release (если создавали Release):

  • Перейдите в раздел "Releases" репозитория
  • Найдите версию "IMPERIA PROMO v1.0.0"
  • Скачайте файл imperia-promo-v1.0.0-release.apk

Способ 2 - Из Artifacts:

  • Вернитесь к завершенному workflow в Actions
  • Прокрутите вниз до секции "Artifacts"
  • Скачайте ZIP архив с APK файлом
  • Распакуйте ZIP и получите APK

🎉 Поздравляем!

У вас есть готовый Android APK файл размером ~25-30 MB, который можно установить на любое Android устройство версии 7.0+

🆘 Решение проблем

❌ Workflow не появляется в Actions

Причины:

  • Файлы не в правильной папке (должно быть .github/workflows/)
  • Неправильное расширение файла (должно быть .yml или .yaml)
  • YAML синтаксические ошибки

Решение: Проверьте структуру папок и синтаксис YAML

❌ Сборка падает с ошибкой

Частые ошибки:

  • npm ci fails → проверьте package.json
  • npm run build fails → убедитесь что сборка работает локально
  • Android SDK errors → обычно решаются автоматически

Решение: Смотрите логи в failed job для точной ошибки

❌ APK создался, но не устанавливается

Проверьте:

  • Включены ли "Неизвестные источники" в Android
  • Не поврежден ли APK при скачивании
  • Попробуйте debug версию вместо release

❓ Нужна дополнительная помощь

Если проблема не решается:

  • Создайте Issue в репозитории с тегом "build-help"
  • Приложите скриншоты ошибок из Actions
  • Укажите какие параметры использовали для сборки
